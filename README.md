## 프로젝트 소개

Study Planner는 시험을 준비하는 대학생을 위한 학습 일정 관리 앱입니다.

시험 기간에는 여러 과목의 강의자료를 정리하고, 남은 기간에 맞춰 공부 계획을 세워야 합니다. 하지만 자료마다 분량과 난이도가 다르고, 계획대로 공부하지 못하는 경우도 많습니다.

이러한 불편함을 줄이기 위해 강의자료 분석부터 학습 일정 생성, 진행 상황 관리까지 하나의 앱에서 처리할 수 있도록 개발했습니다.

## 주요 기능

### 1. AI 기반 강의자료 분석

사용자가 PDF 등의 강의자료를 업로드하면 문서의 내용을 분석하고, 관련 있는 내용을 하나의 학습 단위로 묶습니다.

각 학습 단위에서는 다음 정보를 제공합니다.

- 학습 내용 요약 및 핵심 개념
- 중요도 및 난이도
- 예상 학습시간
- 선행 학습 및 후속 학습 관계

### 2. 자동 학습 일정 생성

시험 날짜와 사용자가 공부할 수 있는 시간을 바탕으로 학습 일정을 생성합니다.

분석된 학습 단위의 예상 학습시간을 활용하여 공부할 내용을 여러 일정으로 나누고 캘린더에 배치합니다.

### 3. 학습 진행 상황 관리

학습 단위별로 완료 여부를 기록할 수 있습니다.

완료한 학습 단위와 남은 학습 단위, 남은 예상 학습시간을 확인할 수 있어 현재 공부 진행 상황을 파악할 수 있습니다.

### 4. 학습 일정 재계획

계획대로 공부하지 못했거나 학습을 완료한 경우, 남은 학습 내용을 기준으로 일정을 다시 생성할 수 있습니다.

학습 완료 여부를 변경하더라도 기존 일정이 자동으로 바뀌지는 않으며, 사용자가 재계획을 요청했을 때 새로운 일정을 배치합니다.

### 5. 학습 캘린더

자동으로 생성된 학습 일정과 사용자가 직접 등록한 일정을 캘린더에서 확인하고 관리할 수 있습니다.

## 서비스 동작 과정

1. **시험 등록:** 시험 과목과 시험 날짜를 입력합니다.
2. **강의자료 업로드:** PDF 등의 학습자료를 등록합니다.
3. **문서 분석:** 자료를 의미 단위로 구분하고 주요 학습 정보를 추출합니다.
4. **일정 생성:** 분석 결과와 학습 가능 시간을 활용하여 공부 일정을 생성합니다.
5. **학습 진행:** 학습 완료 여부를 기록하고 진행 상황을 확인합니다.
6. **일정 재계획:** 필요한 경우 남은 학습 내용을 기준으로 일정을 다시 생성합니다.

## 개발 현황

현재 시험 등록, 강의자료 업로드 및 분석, 학습 단위 관리, 자동 일정 생성과 재계획 기능을 중심으로 개발했습니다.

AI 분석 기능에서는 문서 내용을 여러 학습 그룹으로 구분하고, 그룹별 요약과 핵심 개념, 중요도, 난이도 등을 산출하도록 구현했습니다.

현재는 API 사용량 제한에 대한 대응, 분석 실패 시 재시도 방식, 학습 화면의 가독성 개선 등 안정성과 사용성을 보완하고 있습니다.
